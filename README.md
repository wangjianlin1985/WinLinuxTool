#  WinLinuxTool — Windows / Linux 管理工具

> 一个基于 Delphi 7 的 Windows 桌面管理工具，提供本机 Windows 命令行操作与通过 SSH 管理 Linux 服务器的能力。

## 项目简介

 WinLinuxTool 将本机 Windows 管理终端与 Linux SSH 远程管理整合在一个桌面程序中，方便开发者、运维人员及日常电脑维护人员在统一界面中执行命令、连接服务器并查看终端输出。

项目以 Delphi 7 / VCL 为主要开发环境。Windows 本地终端使用 CMD、PowerShell；本机终端交互实现可采用 Windows ConPTY（伪控制台）机制。Linux 远程管理通过 OpenSSH 客户端建立 SSH 会话。

**注意：** 实际功能以仓库当前提交版本、编译配置及随包组件为准。若某项功能尚未在当前版本验证，请以实际测试结果为准。

## 核心特色：命令分类收藏与管理

### 不必死记硬背，让常用命令随用随查

Windows 和 Linux 的命令数量多、参数复杂，不同系统、不同工具和不同工作场景下的命令也各不相同。 WinLinuxTool 希望解决的一个实际问题，就是帮助用户把命令整理起来，而不是依赖记忆。

你可以将经常使用或暂时记不住的命令，按照系统、用途和工作场景分类保存，逐步建立自己的命令库。需要时打开对应分类，查找命令、查看备注，再复制到终端使用（具体操作以当前版本界面为准）。

例如，可以按以下思路整理：

- **Windows 系统管理：** 网络配置、进程查看、服务管理、磁盘与目录操作。
- **PowerShell：** 系统信息、文件批处理、服务与进程管理。
- **Linux 日常运维：** 文件操作、用户权限、进程、磁盘、网络。
- **服务器与服务管理：** SSH、软件部署、服务状态、日志排查。
- **Docker 与开发工具：** 容器管理、环境检查、常用开发命令。

命令库可以作为个人工作备忘录持续积累。随着使用时间增加，常用操作和排查步骤都能沉淀下来，减少重复搜索和临时查找的时间。

> **记不住命令没关系，把命令整理好，需要时快速找到。**

## 功能概览

### Windows 本机管理

- CMD 命令行操作。
- PowerShell 命令行操作。
- 终端交互输入与输出（取决于当前构建版本的终端实现）。
- 常见目录切换、文件查看、系统信息查询及管理命令。
- 通过目录浏览功能选择工作目录。
- 终端文本选择与复制等基础操作（以当前版本实现为准）。

常见命令示例：

```bat
whoami
ipconfig
systeminfo
dir
cd /d D:\
```

PowerShell 示例：

```powershell
Get-ComputerInfo
Get-Process
Get-Service
Get-ChildItem
```

### Linux SSH 远程管理

- 通过 SSH 连接 Linux 主机。
- 在远程终端中执行 Linux Shell 命令。
- 支持使用 OpenSSH 客户端及其支持的认证方式，具体取决于当前版本配置。
- 可用于查看系统状态、进程、磁盘、网络及服务信息。

常见命令示例：

```bash
uname -a
 uptime
 df -h
 free -h
 ps aux
 systemctl status ssh
```

SSH 是远程连接通道；命令的可用性和执行权限由远程 Linux 系统、登录账号及其权限决定。

## 使用说明

### 1. 启动程序

1. 下载或获取项目发布包。
2. 解压到本地目录。
3. 运行 ` WinLinux集成管理工具.exe`（若发布包提供该文件）。
4. 根据需要进入 Windows 管理或 SSH 管理区域。

建议首次运行时在非系统关键目录中测试，并先确认程序所需运行文件齐全。

### 2. 使用 Windows CMD / PowerShell

1. 打开 Windows 管理终端。
2. 选择 CMD 或 PowerShell 模式。
3. 在命令输入区域输入命令并提交。
4. 根据终端提示继续交互或查看执行结果。
5. 需要切换工作目录时，可使用终端命令或界面提供的目录浏览功能。

CMD 切换盘符及目录可使用：

```bat
cd /d D:\Work
```

PowerShell 切换目录可使用：

```powershell
Set-Location D:\Work
```

请注意：CMD 与 PowerShell 的命令语法、环境变量和脚本规则并不完全相同。

### 3. 使用 SSH 管理 Linux

1. 确认目标 Linux 主机已启用 SSH 服务，并且网络可达。
2. 在 SSH 管理界面填写主机地址、端口、用户名及当前版本支持的认证信息。
3. 发起连接并按提示完成认证。
4. 连接成功后，在远程终端中执行命令。
5. 使用完毕后主动断开会话。

请勿将生产服务器密码、私钥或其他凭据提交到公开仓库。建议使用权限受限的专用账号和 SSH 密钥，并遵循最小权限原则。

## OpenSSH 目录说明

如果发布包采用程序目录内的 OpenSSH 方案，可将 OpenSSH 客户端文件放在主程序同级目录下的 `OpenSSH` 文件夹中。例如：

```text
 WinLinuxTool/
├─  WinLinuxTool.exe
└─ OpenSSH/
   ├─ ssh.exe
   ├─ scp.exe
   └─ sftp.exe
```

程序可按相对程序目录定位客户端，例如 `OpenSSH/ssh.exe`。实际所需文件以当前源码调用方式和发布包为准；不要只复制 `ssh.exe` 而忽略其运行依赖。

建议在目标电脑上验证：
- 程序从含空格或中文字符的路径启动时能否定位 OpenSSH。
- OpenSSH 文件缺失时是否给出清晰提示。
- SSH 主机密钥确认、认证失败和网络中断时的处理行为。

### 模块划分

项目逻辑可按职责理解为以下部分（具体单元名称以源码为准）：

- **主窗体与界面层：** 菜单、页面切换、用户输入及状态展示。
- **Windows 终端层：** 启动和管理本机 CMD / PowerShell 进程，处理输入、输出及终端生命周期。
- **ConPTY 适配层：** 在支持的 Windows 版本上创建伪控制台并连接子进程标准输入输出，使交互式命令行具备持续会话能力。
- **SSH 管理层：** 组织 SSH 客户端参数、建立远程会话并展示远程输出。
- **配置与辅助单元：** 处理配置、文本编码、数据解析及通用功能。

### ConPTY 机制简述

ConPTY（Windows Pseudo Console）是 Windows 提供的伪控制台接口。与每条命令单独启动进程的方式不同，持久终端通常会保持 Shell 进程及其输入输出管道，在同一会话中持续收发数据。

典型流程：

1. 创建输入、输出管道。
2. 创建伪控制台并设置终端尺寸。
3. 使用进程启动属性将伪控制台关联到 CMD 或 PowerShell。
4. 启动 Shell 进程。
5. 将用户输入写入终端输入管道。
6. 异步读取输出并更新界面。
7. 退出时关闭管道、伪控制台并回收子进程资源。

ConPTY 需要受支持的 Windows 系统版本。若项目包含旧版 Windows 兼容路径，应以实际代码和测试结果为准。

### SSH 调用方式

SSH 管理通过 OpenSSH 客户端与远程主机通信。程序需要正确处理可执行文件路径、命令行参数、标准输入输出、退出状态及连接生命周期。

若采用随程序发布的 OpenSSH 目录，建议以程序 EXE 所在目录为基准构造路径，避免依赖用户当前工作目录。涉及用户名、主机名、端口和密钥路径时，应正确处理空格及特殊字符，避免直接拼接不可信输入。
