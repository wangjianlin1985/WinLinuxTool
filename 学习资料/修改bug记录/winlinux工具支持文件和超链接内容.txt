3. 增加公开属性

在 public 区域增加：

注意：这里需要有前面声明的 FOnOpenLocalFile 字段，不能只声明 property。

4. 修改 EvCmdDblClick
找到你现有的过程：
procedure TSshPane.EvCmdDblClick(Sender: TObject);
var
  Cmd, Cat: string;
  I, Cnt: Integer;

把变量声明修改为：
procedure TSshPane.EvCmdDblClick(Sender: TObject);
var
  Cmd, Cat: string;
  Path, URL: string;
  I, Cnt: Integer;

然后找到原有代码：
  if Trim(Cmd) = '' then Exit;

紧接着在它下面插入以下代码：
  { file: 本地文件，使用内置记事本打开 }
  if CompareText(Copy(Cmd, 1, 5), 'file:') = 0 then
  begin
    Path := Trim(Copy(Cmd, 6, MaxInt));

    if Path = '' then Exit;

    { 统一转换路径分隔符 }
    Path := StringReplace(Path, '/', '\', [rfReplaceAll]);

    { 相对路径以 EXE 所在目录为基准 }
    if ExtractFileDrive(Path) = '' then
      Path := IncludeTrailingPathDelimiter(
        ExtractFilePath(Application.ExeName)) + Path;

    Path := ExpandFileName(Path);

    if FileExists(Path) then
    begin
      if Assigned(FOnOpenLocalFile) then
        FOnOpenLocalFile(Path);
    end
    else
      MessageBox(0, PChar('文件不存在：' + Path),
        '提示', MB_OK or MB_ICONWARNING);

    Exit;
  end;

  { href: 网页，使用系统默认浏览器打开 }
  if CompareText(Copy(Cmd, 1, 5), 'href:') = 0 then
  begin
    URL := Trim(Copy(Cmd, 6, MaxInt));

    if URL <> '' then
      ShellExecute(0, 'open', PChar(URL), nil, nil, SW_SHOWNORMAL);

    Exit;
  end;

这里有三个注意事项：
1. 使用 CompareText，所以 FILE:、HREF: 大小写也能识别。
2. Exit 保证文件和网页不会进入后面的 SSH 命令执行逻辑。
3. 普通命令完全不受影响，继续执行原来的代码。

3. 实现 OpenSshLocalFile
在 MainForm.pas 中找到：
procedure TfrmMain.OpenPaths(APaths: TStringList);

在这个过程结束之后（end; 后面），增加：
{ SSH 命令库：打开本地学习资料 }
procedure TfrmMain.OpenSshLocalFile(const APath: string);
var
  L: TStringList;
begin
  L := TStringList.Create;
  try
    L.Add(APath);
    OpenPaths(L);
  finally
    L.Free;
  end;
end;

这样就直接复用了你已有的 OpenPaths()。
它已经实现了：
- 主窗口恢复显示。
- 自动切换到记事本管理标签。
- 调用 FNotepad.OpenFile()。
- 打开后刷新界面。
不需要重复实现这些逻辑。

一个 Delphi 7 兼容性细节：
上面代码中的：
IncludeTrailingPathDelimiter

如果你的 Delphi 7 编译器提示找不到该函数，请替换成 Delphi 7 可用的：
IncludeTrailingBackslash

也就是：
Path := IncludeTrailingBackslash(
  ExtractFilePath(Application.ExeName)) + Path;
