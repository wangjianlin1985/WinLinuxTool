第 12 课 Kafka 与大数据组件集成，主要讲的是数据流转架构和组件之间的协同工作原理，偏向应用架构和开发技术，不是单纯的环境安装部署。

你可以先跳过，等后面学习开发技术时再回来学。
第 12 课主要学习什么？
学习内容	具体讲什么
Kafka + Spark	Kafka 实时消息如何交给 Spark Streaming / Structured Streaming 处理
Kafka + HDFS	Kafka 消息如何采集并保存到 HDFS
Kafka + Spark + HDFS	实现实时数据采集、计算、存储的完整流程
数据流转架构	Producer → Kafka → Spark → HDFS
数据可靠性	消息偏移量 Offset、消费确认、失败恢复
实时数据处理	模拟日志采集、实时统计、结果落盘

举个实际案例
假设你有一个 Java Web 网站，用户不断访问网站，产生访问日志。
Java Web 网站
不断产生用户访问日志
↓
Kafka
接收和缓存日志消息
↓
Spark Streaming
实时读取、分析、统计日志
↓
HDFS
保存处理后的数据，供后续分析

这就是典型的大数据实时处理架构。

我的建议
你目前主要目标是把大数据平台部署起来，所以第 12 课可以先跳过。
等完成所有组件环境部署后，再集中学习：
- Java 如何连接 Kafka、Spark、HDFS。
- Python 如何连接这些大数据组件。
- 如何编写完整的数据采集、实时计算和存储程序。
第 12 课属于后续开发实战课程，不需要现在学习。
