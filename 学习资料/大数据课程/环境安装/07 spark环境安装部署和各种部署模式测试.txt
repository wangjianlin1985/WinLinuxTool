五、配置 spark-env.sh
编辑：vi $SPARK_HOME/conf/spark-env.sh
这份文件主要负责 Spark 的运行环境、Java、Python、Hadoop 配置，以及 Standalone 集群的节点参数。
建议统一配置如下：

# ==========================================
# Spark Common Environment
# ==========================================

# Java
export JAVA_HOME=/usr/local/bigdata/jdk

# Hadoop Configuration
export HADOOP_HOME=/usr/local/bigdata/hadoop
export HADOOP_CONF_DIR=$HADOOP_HOME/etc/hadoop
export YARN_CONF_DIR=$HADOOP_HOME/etc/hadoop

# Python
export PYSPARK_PYTHON=/usr/bin/python3
export PYSPARK_DRIVER_PYTHON=/usr/bin/python3

# ==========================================
# Spark Standalone Configuration
# 仅使用 Standalone 模式时启用
# ==========================================

# export SPARK_MASTER_HOST=master
# export SPARK_MASTER_PORT=7077
# export SPARK_MASTER_WEBUI_PORT=8080

# export SPARK_WORKER_CORES=2
# export SPARK_WORKER_MEMORY=2g
# export SPARK_WORKER_WEBUI_PORT=8081

# ==========================================
# Spark Network Configuration
# ==========================================

# export SPARK_LOCAL_IP=192.168.79.10
# export SPARK_PUBLIC_DNS=master


这里有几个地方需要理解：
参数			作用
JAVA_HOME		Spark 使用的 Java
HADOOP_HOME		Hadoop 安装目录
HADOOP_CONF_DIR	Hadoop 配置文件目录
YARN_CONF_DIR		YARN 配置文件目录
PYSPARK_PYTHON		Executor 使用的 Python
PYSPARK_DRIVER_PYTHON	Driver 使用的 Python
SPARK_MASTER_HOST	Standalone Master 主机名
SPARK_WORKER_CORES	Standalone Worker 可用 CPU 核数
SPARK_WORKER_MEMORY	Standalone Worker 可用内存

注意：
SPARK_MASTER_HOST、SPARK_WORKER_CORES 等参数属于 Standalone 模式，YARN 模式不需要启用。
另外，spark-env.sh 中的环境变量不会自动替代所有 YARN Cluster 模式下的容器环境变量，后面还会在 spark-defaults.conf 中配置 Python 环境。

六、配置 spark-defaults.conf
这是本节比较重要的一份配置文件。
我们把三种模式的参数放在同一个文件中：
- Local 模式：默认全部注释。
- YARN 模式：默认启用。
- Standalone 模式：默认全部注释。
以后切换模式，只需要修改这里的注释即可。

编辑：vi $SPARK_HOME/conf/spark-defaults.conf
写入以下完整配置：

# ==========================================
# Spark Common Configuration
# ==========================================

# Event Log
spark.eventLog.enabled                  false

# Python
spark.pyspark.python                     /usr/bin/python3
spark.pyspark.driver.python              /usr/bin/python3

# Resource
spark.executor.cores                     1
spark.executor.memory                    1g
spark.driver.memory                      1g

# ==========================================
# 1. Local Mode
# 本地测试模式
# ==========================================

# spark.master                           local[*]


# ==========================================
# 2. YARN Mode
# 默认使用 YARN 模式
# ==========================================

spark.master                             yarn
spark.submit.deployMode                  client

# Python Environment for YARN
spark.yarn.appMasterEnv.PYSPARK_PYTHON   /usr/bin/python3
spark.yarn.appMasterEnv.PYSPARK_DRIVER_PYTHON /usr/bin/python3

# ==========================================
# 3. Standalone Mode
# Spark 自带 Master / Worker
# ==========================================

# spark.master                           spark://master:7077

# spark.submit.deployMode                client



这里解释几个关键参数。

1. spark.master
决定 Spark 使用哪一种运行模式：
参数	模式
local[*]	Local
yarn	YARN
spark://master:7077	Standalone

2. spark.submit.deployMode
决定 Driver 的运行位置：
参数	作用
client	Driver 在提交客户端运行
cluster	Driver 在集群容器中运行

本节默认使用 YARN Client 模式。
因为我们采用 Windows 开发、SSH 远程提交的方式，所以实际提交命令会在 Linux master 上执行，Driver 也运行在 Linux 上。

3. 为什么配置两个 Python 环境？
spark.pyspark.python
spark.pyspark.driver.python
它们分别指定 Executor 和 Driver 使用的 Python。

另外：
spark.yarn.appMasterEnv.PYSPARK_PYTHON
spark.yarn.appMasterEnv.PYSPARK_DRIVER_PYTHON
用于 YARN ApplicationMaster 环境，尤其是以后切换到 YARN Cluster 模式时，需要正确设置容器中的 Python 环境。

Spark 配置文件支持通过命令行参数覆盖默认配置，所以以后也可以通过 --master 和 --deploy-mode 临时切换，不必每次修改配置文件。

十一、三种运行模式如何切换？
启动spark standalone模式修改：/usr/local/bigdata/spark-4.0.5/conf/spark-env.sh  打开其中其中spark standalone的配置的注释
Standalone 模式还需要启动 Spark 自带的 Master、Worker 服务。
例如：
$SPARK_HOME/sbin/start-master.sh
$SPARK_HOME/sbin/start-workers.sh
停止：
$SPARK_HOME/sbin/stop-workers.sh
$SPARK_HOME/sbin/stop-master.sh

模式修改：/usr/local/bigdata/spark-4.0.5/conf/spark-defaults.conf  用什么模式就打开对应模式的注释
重要：三种模式的参数虽然放在同一份配置文件里，但同一时间只能启用一个 spark.master。不要同时取消三种模式的注释。

另外，命令行参数优先级高于 spark-defaults.conf，因此也可以临时指定：
spark-submit --master local[*] ...

不需要修改默认的 YARN 配置。

十二、Windows 开发 PySpark，远程提交 Linux
Windows 不需要安装：
- JDK
- Python
- Spark
- Hadoop
Windows 只负责开发和文件传输，实际运行环境全部在 Linux。

例如，Windows 编写：
from pyspark.sql import SparkSession

spark = SparkSession.builder \
    .appName("PySparkTest") \
    .getOrCreate()

data = [(1, "张三"), (2, "李四"), (3, "王五")]

df = spark.createDataFrame(data, ["id", "name"])

df.show()

spark.stop()

通过 SFTP 将文件上传到 Linux，例如：
/home/dsj_admin/pyspark/test.py


然后通过 SSH 在 Linux 上执行：
spark-submit /home/dsj_admin/pyspark/test.py

由于默认配置是 YARN，程序会自动提交到 YARN。
这里使用的是 YARN Client 模式，Driver 在 Linux master 上运行，而不是 Windows 上运行。
这就实现了 Windows 开发、Linux 运行、YARN 调度。

十五、编写 Spark 五种模式综合测试程序
这里测试五种场景：
编号	测试模式	Spark Master	Driver 位置
1	Local 单线程	local	本地
2	Local 多线程	local[*]	本地
3	YARN Client	yarn	Linux master
4	YARN Cluster	yarn	YARN 容器
5	Standalone Client	spark://master:7077	Linux master

注意：YARN Cluster 模式要求 Python 程序和所需依赖在 Linux 集群容器中可用。Windows 只负责编写和上传代码。

1. 创建测试程序
在 Linux 上创建目录：mkdir -p /home/dsj_admin/pyspark
创建文件：vi /home/dsj_admin/pyspark/spark_mode_test.py

写入完整代码：
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
Spark 4.0.5 五种运行模式综合测试

运行模式：
1. local
2. local[*]
3. yarn-client
4. yarn-cluster
5. standalone-client
"""

import sys
import argparse
from pyspark.sql import SparkSession
from pyspark.sql.functions import sum, count, avg


def main():

    parser = argparse.ArgumentParser(
        description="Spark 五种运行模式综合测试"
    )

    parser.add_argument(
        "--mode",
        required=True,
        choices=[
            "local",
            "local-all",
            "yarn-client",
            "yarn-cluster",
            "standalone-client"
        ],
        help="选择 Spark 运行模式"
    )

    args = parser.parse_args()

    modes = {
        "local": {
            "master": "local",
            "deploy": "client"
        },
        "local-all": {
            "master": "local[*]",
            "deploy": "client"
        },
        "yarn-client": {
            "master": "yarn",
            "deploy": "client"
        },
        "yarn-cluster": {
            "master": "yarn",
            "deploy": "cluster"
        },
        "standalone-client": {
            "master": "spark://master:7077",
            "deploy": "client"
        }
    }

    config = modes[args.mode]

    print("=" * 60)
    print("Spark 4.0.5 综合测试")
    print("测试模式:", args.mode)
    print("Master:", config["master"])
    print("Deploy:", config["deploy"])
    print("=" * 60)

    spark = (
        SparkSession.builder
        .appName("SparkModeTest-" + args.mode)
        .master(config["master"])
        .config("spark.submit.deployMode", config["deploy"])
        .getOrCreate()
    )

    sc = spark.sparkContext

    print("Spark Version:", spark.version)
    print("Application ID:", sc.applicationId)
    print("Master:", sc.master)
    print("Default Parallelism:", sc.defaultParallelism)

    # ======================================
    # 测试一：RDD 分布式计算
    # ======================================

    print("\n[测试一] RDD 分布式计算")

    numbers = sc.parallelize(range(1, 100001))

    total = numbers.sum()

    print("1~100000 累加结果:", int(total))

    # ======================================
    # 测试二：DataFrame 创建与查询
    # ======================================

    print("\n[测试二] DataFrame 数据处理")

    data = [
        (1, "张三", "开发部", 8000),
        (2, "李四", "开发部", 10000),
        (3, "王五", "测试部", 7000),
        (4, "赵六", "测试部", 9000),
        (5, "钱七", "运维部", 8500)
    ]

    columns = ["id", "name", "department", "salary"]

    df = spark.createDataFrame(data, columns)

    df.show()

    # ======================================
    # 测试三：DataFrame 聚合分析
    # ======================================

    print("\n[测试三] 部门薪资统计")

    result = (
        df.groupBy("department")
        .agg(
            count("*").alias("人数"),
            sum("salary").alias("工资总额"),
            avg("salary").alias("平均工资")
        )
    )

    result.show()

    # ======================================
    # 测试四：SQL 查询
    # ======================================

    print("\n[测试四] Spark SQL")

    df.createOrReplaceTempView("employees")

    sql_result = spark.sql("""
        SELECT department,
               COUNT(*) AS employee_count,
               MAX(salary) AS max_salary
        FROM employees
        GROUP BY department
        ORDER BY max_salary DESC
    """)

    sql_result.show()

    # ======================================
    # 测试五：任务执行与分区
    # ======================================

    print("\n[测试五] 分区任务执行")

    partition_count = numbers.getNumPartitions()

    print("RDD 分区数量:", partition_count)

    # ======================================
    # 测试完成
    # ======================================

    print("\n" + "=" * 60)
    print("Spark 测试全部完成！")
    print("测试模式:", args.mode)
    print("Application ID:", sc.applicationId)
    print("=" * 60)

    spark.stop()


if __name__ == "__main__":
    try:
        main()
    except Exception as e:
        print("\nSpark 测试失败:", str(e))
        sys.exit(1)

十六 PySpark 程序在 Spark Standalone 模式下不支持 cluster 提交方式，咱们用java程序演示

3、编写 Java 测试程序
文件：src/main/java/com/bigdata/SparkStandaloneClusterTest.java
完整代码：

package com.bigdata;

import org.apache.spark.api.java.JavaRDD;
import org.apache.spark.api.java.JavaSparkContext;
import org.apache.spark.sql.Dataset;
import org.apache.spark.sql.Row;
import org.apache.spark.sql.RowFactory;
import org.apache.spark.sql.SparkSession;
import org.apache.spark.sql.types.DataTypes;
import org.apache.spark.sql.types.StructType;

import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;
import java.util.stream.IntStream;

public class SparkStandaloneClusterTest {

    public static void main(String[] args) {

        SparkSession spark = null;

        try {

            // ======================================
            // 1. 创建 SparkSession
            // ======================================

            spark = SparkSession.builder()
                    .appName("SparkStandaloneClusterTest")
                    .getOrCreate();

            System.out.println("====================================");
            System.out.println("Spark Standalone Cluster 测试");
            System.out.println("====================================");

            System.out.println("Spark Version: "
                    + spark.version());

            System.out.println("Application ID: "
                    + spark.sparkContext().applicationId());

            System.out.println("Master: "
                    + spark.sparkContext().master());

            System.out.println("====================================");

            // ======================================
            // 2. RDD 分布式计算
            // ======================================

            System.out.println("\n[测试一] RDD 分布式计算");

            JavaSparkContext sc =
                    JavaSparkContext.fromSparkContext(
                            spark.sparkContext());

            List<Integer> numbers = IntStream.rangeClosed(1, 100000)
                    .boxed()
                    .collect(Collectors.toList());

            JavaRDD<Integer> rdd = sc.parallelize(numbers, 4);

            int sum = rdd.reduce(Integer::sum);

            System.out.println("RDD 分区数量: "
                    + rdd.getNumPartitions());

            System.out.println("1~100000 累加结果: "
                    + sum);

            // ======================================
            // 3. DataFrame 测试
            // ======================================

            System.out.println("\n[测试二] DataFrame 数据处理");

            List<Row> employees = Arrays.asList(
                    RowFactory.create(1, "张三", "开发部", 8000),
                    RowFactory.create(2, "李四", "开发部", 10000),
                    RowFactory.create(3, "王五", "测试部", 7000),
                    RowFactory.create(4, "赵六", "测试部", 9000),
                    RowFactory.create(5, "钱七", "运维部", 8500)
            );

            StructType schema = new StructType()
                    .add("id", DataTypes.IntegerType)
                    .add("name", DataTypes.StringType)
                    .add("department", DataTypes.StringType)
                    .add("salary", DataTypes.IntegerType);

            Dataset<Row> df = spark.createDataFrame(
                    employees, schema);

            df.show();

            // ======================================
            // 4. Spark SQL 测试
            // ======================================

            System.out.println("\n[测试三] Spark SQL");

            df.createOrReplaceTempView("employees");

            Dataset<Row> result = spark.sql(
                    "SELECT department, " +
                    "COUNT(*) AS employee_count, " +
                    "SUM(salary) AS total_salary, " +
                    "AVG(salary) AS avg_salary " +
                    "FROM employees " +
                    "GROUP BY department " +
                    "ORDER BY total_salary DESC"
            );

            result.show();

            // ======================================
            // 5. 分布式任务测试
            // ======================================

            System.out.println("\n[测试四] 分布式任务执行");

            long count = rdd.map(x -> x * 2)
                    .filter(x -> x % 4 == 0)
                    .count();

            System.out.println("满足条件的数据数量: "
                    + count);

            // ======================================
            // 6. 测试完成
            // ======================================

            System.out.println("\n====================================");
            System.out.println("Spark Standalone Cluster 测试成功！");
            System.out.println("Application ID: "
                    + spark.sparkContext().applicationId());
            System.out.println("RDD 累加结果: " + sum);
            System.out.println("====================================");

        } catch (Exception e) {

            System.err.println("Spark 测试失败！");
            e.printStackTrace();

            System.exit(1);

        } finally {

            if (spark != null) {
                spark.stop();
            }

        }
    }
}



5、Maven 编译打包
在 Windows 开发电脑上，进入项目根目录：
mvn clean package
成功后生成：target/SparkStandaloneClusterTest-1.0.0.jar
将这个 JAR 上传到 Linux：/home/dsj_admin/pyspark/SparkStandaloneClusterTest-1.0.0.jar

5、启动 Standalone 集群
在 Linux master 上执行：$SPARK_HOME/sbin/start-master.sh
启动 Worker：$SPARK_HOME/sbin/start-workers.sh
检查：jps
应该能看到：
Master
Worker
打开 Spark Master Web UI：http://master:8080
确认 Worker 状态为 ALIVE。

6、提交 Standalone Cluster 任务
执行：
spark-submit \
--class com.bigdata.SparkStandaloneClusterTest \
--master spark://master:7077 \
--deploy-mode cluster \
/home/dsj_admin/pyspark/SparkStandaloneClusterTest-1.0.0.jar


本节核心测试命令
这里最重要的参数：
--deploy-mode cluster
它表示 Driver 不在提交客户端运行，而是由 Standalone Master 调度到 Worker 上运行。
因为当前是单机伪分布式，Master 和 Worker 都在 master 上，所以 Driver 最终也会运行在这台机器上。

7、查看运行结果
打开：http://master:8080
在 Master 页面查看 Applications。
找到：SparkStandaloneClusterTest
点击对应的 Driver，查看运行状态和日志。

也可以查看 Worker 的 Driver 日志：
ls -lh $SPARK_HOME/work/
实际 Driver 日志通常位于：
$SPARK_HOME/work/driver-*/stdout
$SPARK_HOME/work/driver-*/stderr
具体目录取决于 Worker 的工作目录配置。
