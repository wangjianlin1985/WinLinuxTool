第13讲安装的 Flink 环境可以直接在 Windows 电脑上使用 Java 编写程序，通过网络连接 Linux 虚拟机中的 Flink 集群，提交任务并执行。

不过需要区分两种运行方式。
1. Windows Java 程序连接 Linux Flink
你现在的环境是：Windows 电脑
Java 开发环境（IDEA / Eclipse）
编写 Flink Java 程序 → 提交任务

Rocky Linux 9 虚拟机
Flink JobManager：接收任务、调度任务
Flink TaskManager：实际执行计算任务
Flink Web UI：8081 端口
你的 Windows Java 程序负责开发，Linux 负责运行 Flink 集群，两者通过网络通信。

2. Windows 需要安装什么？
Windows 端只需要：
软件		用途
JDK		编译和运行 Java 程序
IDEA		编写 Java 程序
Maven		管理 Flink 依赖
Flink Java API 依赖	编写 Flink 计算程序
Windows 不需要再安装一套 Flink 服务端，也不需要安装 JobManager 或 TaskManager。

3. Linux Flink 环境需要开放什么端口？
你第13讲部署的 Flink 默认端口主要有：
端口	用途
8081	Flink Web UI（你当前配置的管理页面）
6123	JobManager RPC（取决于版本和配置）
6124	TaskManager RPC（取决于版本和配置）
6125	Blob Server（取决于版本和配置）

注意：上面 RPC 端口是常见配置示例，具体以你安装的 Flink 2.2.2 config.yaml 实际配置为准，不能直接认定全部是这些端口。

五、编写 Java Flink 程序
创建文件：src/main/java/com/demo/FlinkOrderDemo.java

我们实现一个订单金额实时汇总程序。
1. 模拟订单数据
订单格式：
订单编号,商品分类,金额

例如：
1001,手机,3999
1002,电脑,5999
1003,手机,2999
1004,平板,1999
1005,电脑,6999
1006,手机,1999


2. Java 完整代码
 

package com.demo;

import org.apache.flink.api.java.tuple.Tuple2;
import org.apache.flink.streaming.api.environment.StreamExecutionEnvironment;
import org.apache.flink.streaming.api.datastream.DataStream;
import org.apache.flink.api.common.typeinfo.Types;


public class FlinkOrderDemo {

    public static void main(String[] args) throws Exception {

        // 1. 获取 Flink 执行环境
        StreamExecutionEnvironment env =
                StreamExecutionEnvironment.getExecutionEnvironment();

        // 2. 模拟订单数据
        DataStream<String> orders = env.fromElements(
                "1001,手机,3999",
                "1002,电脑,5999",
                "1003,手机,2999",
                "1004,平板,1999",
                "1005,电脑,6999",
                "1006,手机,1999"
        );

        // 3. 提取商品分类和订单金额
        DataStream<Tuple2<String, Integer>> amounts =
                orders.map(line -> {
                    String[] fields = line.split(",");

                    return Tuple2.of(
                            fields[1],
                            Integer.parseInt(fields[2])
                    );
                }).returns(
                        Types.TUPLE(
                                Types.STRING,
                                Types.INT
                        )
                );

        // 4. 按商品分类分组
        // 5. 按商品分类分组并累计金额
        DataStream<Tuple2<String, Integer>> result =
                amounts
                        .keyBy(data -> data.f0)
                        .sum(1);


        // 6. 输出结果
        result.print();

        // 7. 提交 Flink 作业
        env.execute("Flink Order Statistics");
    }
}

3. 这段程序做了什么？
Flink 数据处理流程
订单数据源 fromElements()
1001,手机,3999 ...

map() 数据转换
提取商品分类 + 金额

keyBy() 分组
手机 / 电脑 / 平板

sum(1) 累计金额
按商品分类累计订单金额

print() 输出计算结果

注意这里的 sum(1) 是对 Tuple2 的第2个字段（金额）累计，不是统计订单数量。

九、向 Linux Flink 集群提交任务
这是整个实验的核心。
在 Linux 终端执行：
flink run \
-c com.demo.FlinkOrderDemo \
/data/flink/jobs/flink-windows-demo-1.0.jar

其中：
参数	说明
flink run	提交 Flink 作业
-c	指定 Java 主类
com.demo.FlinkOrderDemo	我们编写的 Java 主类
JAR 路径	Java 程序编译打包后的文件

提交后 Flink CLI 会向集群提交任务，JobManager 接收任务并调度，TaskManager 执行实际的数据计算。
如果提交成功，命令终端会显示 Job ID，类似：
Job has been submitted with JobID xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
实际 JobID 是一串十六进制字符。

tail -n 100 $FLINK_HOME/log/*.out

grep -n "手机\|电脑\|平板" $FLINK_HOME/log/*.out

电脑	12998
平板	1999

计算逻辑验证通过：
- 手机：3999 + 2999 + 1999 = 8997
- 电脑：5999 + 6999 = 12998
- 平板：1999
由于 print() 的输出顺序可能交错，并且会输出每次累计变化，所以日志中可能不是只有3条最终结果。

三、编写远程提交 Java 程序
创建 FlinkRemoteDemo.java：

package com.flink;

import org.apache.flink.api.common.typeinfo.Types;
import org.apache.flink.api.java.tuple.Tuple2;
import org.apache.flink.streaming.api.datastream.DataStream;
import org.apache.flink.streaming.api.environment.StreamExecutionEnvironment;

public class FlinkRemoteDemo {

    private static final String FLINK_HOST = "192.168.79.10";
    private static final int FLINK_PORT = 8081;

    public static void main(String[] args) throws Exception {

        // Windows 本地 JAR 文件路径
        String jarPath = System.getProperty("user.dir")
                + "/target/flink-remote-demo-1.0.jar";

        System.out.println("================================");
        System.out.println("准备连接 Linux Flink 集群");
        System.out.println("地址：" + FLINK_HOST);
        System.out.println("端口：" + FLINK_PORT);
        System.out.println("程序：" + jarPath);
        System.out.println("================================");

        // 创建远程执行环境
        StreamExecutionEnvironment env =
                StreamExecutionEnvironment.createRemoteEnvironment(
                        FLINK_HOST,
                        FLINK_PORT,
                        2,
                        jarPath
                );

        env.setParallelism(2);

        // 模拟订单数据
        DataStream<String> orders = env.fromElements(
                "1001,手机,3999",
                "1002,电脑,5999",
                "1003,手机,2999",
                "1004,平板,1999",
                "1005,电脑,6999",
                "1006,手机,1999"
        );

        // 提取商品分类和金额
        DataStream<Tuple2<String, Integer>> amounts =
                orders.map(line -> {

                    String[] fields = line.split(",");

                    return Tuple2.of(
                            fields[1],
                            Integer.parseInt(fields[2])
                    );

                }).returns(
                        Types.TUPLE(
                                Types.STRING,
                                Types.INT
                        )
                );

        // 按商品分类分组并累计金额
        DataStream<Tuple2<String, Integer>> result =
                amounts
                        .keyBy(data -> data.f0)
                        .sum(1);

        // 输出到 TaskManager 日志
        result.print();

        System.out.println("正在提交远程 Flink 任务...");

        env.execute("Windows Remote Flink Order Demo");

        System.out.println("Flink 任务执行完成！");
    }
}



这里最重要的是：
StreamExecutionEnvironment.createRemoteEnvironment(
        FLINK_HOST,
        FLINK_PORT,
        2,
        jarPath
);
 

参数分别是：
参数		作用
FLINK_HOST	Linux JobManager 地址
FLINK_PORT	Flink REST 端口
2		任务默认并行度
jarPath		Windows 本地生成的用户程序 JAR
Flink 客户端会将用户程序提交给远程集群，不需要你手工 SCP 上传。官方 API 也明确说明，远程环境会把程序提交到集群执行。
